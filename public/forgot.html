fuellog
mot de passe oublié

Pas d'e-mail ici : la réinitialisation se fait sur le serveur où tourne FuelLog, avec un petit script de secours.

  1. Ouvre un terminal du serveur FuelLog (console du LXC, ou ssh …).
  2. Efface le mot de passe (le panel redevient ouvert) : 
    sudo bash /opt/fuellog/reset-admin-password.sh
    …ou définis-en un nouveau directement : 
    sudo bash /opt/fuellog/reset-admin-password.sh "nouveau-mot-de-passe"
  3. Redémarre le service : sudo systemctl restart fuellog (ou pm2 restart fuellog).

Ensuite, reconnecte-toi — ou redéfinis un mot de passe dans Paramètres → Compte & sécurité.
