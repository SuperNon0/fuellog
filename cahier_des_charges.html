01
Présentation du projet

FuelLog est une application web progressive (PWA) de suivi de carburant personnel, hébergée sur un serveur Proxmox via un container LXC Debian. Elle est accessible depuis n'importe quel appareil (iPhone, ordinateur) via l'URL fuellog.super-nono.cc, sécurisée par Cloudflare Access (authentification par email).

L'application permet de suivre tous ses pleins d'essence, analyser ses dépenses, surveiller la précision de l'ordinateur de bord, et trouver les stations les moins chères à proximité.

05
Logique métier — Les 2 phases
Phase 1
Au moment du plein
  • Date + type carburant
  • Station (favoris → proches → manuel)
  • ODB annoncé (km restants affichés)
  • Prix total payé (€)
  • Litres + prix/L (optionnels)
  • kmDepart repris du plein précédent
Phase 2
Au plein suivant (avant de faire le plein)
  • Kilométrage total atteint
  • ODB restant affiché par la voiture
  • → Calcul automatique précision

Formule de précision ODB

kmParcourus  = kmTotal - kmDepart
précision %  = (kmParcourus + estimRestante) / estimPlein × 100

Exemple :
  kmDepart=146716 · kmTotal=147394 → kmParcourus=678
  estimPlein=866 · estimRestante=95
  précision = (678 + 95) / 866 = 89.3%

07
Onglet Stations — Détail

Noms des stations

Fichier stations_name.json (798 Ko, ~39 000 entrées) issu du projet hass-prixcarburant. Chaque entrée : { "id": { "name": "Super U Aigues-Mortes", "brand": "Super U" } }. Lookup dans routes/stations.js au moment du parsing.

Coordonnées

Utiliser s.geom.lat et s.geom.lon (déjà en degrés décimaux). Fallback : latitude / 100000.

Prix

Utiliser les champs plats gazole_prix, e10_prix, sp95_prix, sp98_prix, e85_prix. Fallback : parser le champ prix (JSON string) avec normalisation des accents.

Refresh prix favoris

Route GET /api/favoris/refresh-prix — 1 seul appel avec WHERE id IN (id1, id2, ...). Stocke en prix_json dans SQLite. Déclenché automatiquement à l'ouverture de l'onglet Favoris.
